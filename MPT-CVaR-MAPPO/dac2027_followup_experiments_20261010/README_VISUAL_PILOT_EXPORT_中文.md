# 完整 pilot 决策导出及元数据入口字节连续性：仅源码准备

本步不是实际 pilot、冻结文件或独立审查。`RealCompletedPilotExporter` 的实际构造、导出、读取均为0；不提供CLI，不运行模型、pilot、拟合、选择、测试日程生成或训练。

未来真实调用必须消费同一个成功的 `RealCompletePilotFreezeEvidence` 对象：完整配对无优化器工程登记、真实两臂 CUDA smoke、源修复和工程入口复审、真实用户网络方向及六类额外独立充分性检查均不可省略。首阶段登记及同一 foundation FIFO 回放不能自动成为完整 pilot。

导出仅保存已独立确认的 cal/validation 决策和全部原始输入指纹。原共同角色日程、catalog、30条移动文件、raw/source/model/smoke/human/independent assessment/selection 必须完整继承且不可替换；被选择的日程也必须在已审查输入集合中，不临时增加未审查材料。语义身份由原登记和选择身份构成，改输出路径、JSON编码或审查交付路径不产生重试许可。失败保留锁和新目录证据，不能追加、覆盖、合并部分输出或重新选择有利条件。

未来成功导出的状态仅为 `cal_validation_generation_design_frozen_not_formal_entry`。它明确不授权元数据生成、不冻结完整正式协议、不证明十训练或120测试完成。输出路径只能是 `protocol/pilot_exports` 下新的短直接子目录。当前没有创建这类完成文件。

本轮检查仅对纯语义身份、人工引用地图、不重绑合并、缺真实对象早拒绝，以及原生产者/消费者字段与边界接线做源码检查。没有伪造 actual review、用户授权、MODEL、完整pilot/PASS标记；没有调用 exporter、实际 reader 或 generator。实际运行守卫、独立判断和真实失败保存路径尚未执行，作者自检不能当作独立审计。
