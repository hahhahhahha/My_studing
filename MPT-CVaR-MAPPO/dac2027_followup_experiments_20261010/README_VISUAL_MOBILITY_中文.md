# 视觉路线B：物理时间移动适配器（工程基础）

新增入口 `scripts/physical_mobility.py` 独立于旧算法包，不改旧轨迹读取器。它按文件名取前30个KAIST原始Time/x/y文件，读取实际时间戳，并要求逐行10秒间隔；在给定的物理秒时刻做线性位置插值。因此50ms决策推进50ms，而不是跳过一整条10秒轨迹记录。

禁止越出所有用户共同支持时间，不循环、不保持末位置、不外推，也不自动合成用户。服务器位置只由显式传入的训练时间窗内原始顶点和边界插值确定区域，再用显式种子抽取；后续验证/测试区域极值不参与放置。

检查包含明确标注的人工小轨迹（插值、未来极值不参与训练放置、越界/错误时间网格拒绝）以及真实30用户轨迹的0.05/5/10秒关系、500秒工程窗口和原始SHA。检查脚本中的0–500秒窗口、seed123仅是工程测试输入，不是最终训练/验证划分或服务器放置协议；正式时间窗、隔离带及放置种子仍须在校准/验证预实验阶段明确冻结。

此模块只能支持物理时间和训练区域访问边界检查。连续FIFO执行、预测压力广播、actor/critic接入、各基线相同输入、共同日程、奖励与归一化尚需完整集成和fresh独立入口检查；不能据此宣称视觉策略实验完成或QLA有益。原服务测量/模型、旧算法/结果及论文保持不变。
