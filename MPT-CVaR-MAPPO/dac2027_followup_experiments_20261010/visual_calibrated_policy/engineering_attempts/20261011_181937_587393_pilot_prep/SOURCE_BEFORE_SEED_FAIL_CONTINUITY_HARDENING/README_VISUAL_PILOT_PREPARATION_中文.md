# 校准／验证工程 pilot 准备入口（源码，未实际运行）

`scripts/visual_pilot_preparation.py` 区分 **pilot 前工程准备** 与已有“真实完成 pilot 后”的正式训练入口，避免循环依赖。不要求最终测试请求 SHA、十份训练、最终权重或完成 pilot 证明才能开始工程准备；也不提前生成测试日程。

当前实际准备对象／模型／pilot／冻结均为零。原源审查 FAIL 保留，修复独立复审仍 PENDING；GPU 门槛未过，用户未答网络选择。没有填写候选实际条件、用户授权、完成记录或 PASS。旧冒烟计划因新增源过期，不重封／运行。

纯函数只校验显式候选描述：30 用户、四个 action 对齐资源配置、32 等待、50ms 决策、100ms 广播、完整共同尺度／终末／H 候选、原 calibration 和 validation 角色／日程字节及语义绑定。同一条件机械派生两方法描述，无方法专用条件。候选不是冻结，也不是收集成功。

真实构造路径须有外部 SHA 绑定的当前实际双臂 CUDA forward／update／roundtrip 冒烟、保留原 FAIL 身份的 fresh gpt-6-astra xhigh Type-A 修复复审、以及独立 **无优化器 cal-validation 闭合工程阶段** 入口审查。审查必须核对真实用户消息来源／原文和网络方向，并绑定完整原角色输入。写在本地 JSON 的 `origin=user`、作者声明或布尔值不能证明用户授权；不得为过门槛伪造记录或审查。此路径仅支持用户明确选择保留已登记 2MHz 不利条件；高带宽必须另行授权和修复／审查 empty-request 公平输入，不能退回默认条件。

真实准备对象没有 run／训练／生成／冻结 API，也不构造模型。下一步工程 executor 才能消费同一 live 对象，逐条件前后检查原字节，再单独验证实际模型、校准来源尺度／几何、完整物理窗口、队列／收据和质量守恒；不能用对象或描述代替这些验证。此处尚不执行这些实际 executor 保护。校准闭合收集和验证只读工程明确无优化器更新，不是十份正式训练或 120 cells，更不能把这第一阶段当完整 pilot。

完整 pilot 的参数确认／冻结与真实证据登记尚待后续源码；最终 metadata-only 独立许可、共同日程、完整冻结协议及正式 Type-A 入口保持原独立阶段。负面／零完成／drop／unfinished 不筛除，test 真值、测试结果和策略优势不得用于选择。

`scripts/check_visual_pilot_preparation.py` 只用**明确人工条件／虚构路径／SHA**测纯描述和坏字段拒绝，静态检查真实门槛，并测试缺失 bindings 的早拒绝；不伪造 actual smoke／用户回复／PASS 来走真实成功路径，不导入 Torch、打开测试计时 CSV、拟合、构造模型或执行 pilot。真实权限、输入读取、物理窗、序列化与执行路径尚未测试；作者自检不是独立审查。
