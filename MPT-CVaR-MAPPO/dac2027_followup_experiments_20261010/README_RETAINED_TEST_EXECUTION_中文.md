# 固定权重完整测试入口（仅源码准备）

当前真实模型加载、队列／策略执行、训练、验证和正式测试均为 **0**。本文件不是运行许可；没有新增模型结果、正式冻结协议或独立 PASS。资源门槛失败和视觉修复独立复审 PENDING 时，不构造 `RealFrozenWeightTestGridRunner` 或调用 `run_once`。

`scripts/retained_test_grid_execution.py` 将已有单 cell 评估与完整登记接在一起：

- 输入只能是实际 `FrozenTestExecutionContract`：不可变完整协议、真实两臂 CUDA smoke、fresh gpt-6-astra xhigh Type-A 完整入口，以及同一协议下训练／验证后登记的十份自身最终权重。所有源、保护输入、共同日程、实际权重和审查文件在边界复核。
- 活跃合同内存中的登记也必须与外部 SHA 绑定的登记文件语义完全一致，不能只检查磁盘文件后放任内存方法／种子／权重路径改写。整个网格的固定顺序／维度入口记录和每个实际加载见证纳入最终输入指纹；这些真实路径尚未执行。
- 原验证专用加载器不被改名复用。新测试加载器核对实际登记的 **方法与种子**，只反序列化自身 `MODEL_STATE.pt`，加载后与外部登记参数 SHA 精确一致才供策略使用；不恢复优化器、虚拟 H、MV 或训练 RNG。构造器会创建未执行的优化器并可能重新设定 Torch RNG，单 cell 内确定性执行仍须 RNG／参数完全不变。
- 第一次模型构造使用原工厂的 GPU 空闲门槛与独立进程 seeded kernel；仅构造一个未用于动作的真实 QLA 架构参考。以后每个学习 cell 在同一已验证 CUDA 进程内重新构造、正确加载自己的最终权重，避免对自身已分配显存重复执行“GPU 空闲”门槛。PPO 使用同一历史模型类与原工厂默认结构。没有随机初始化策略替代、CPU 回退、未知进程清理或资源门槛放宽。
- 顺序固定为声明负载、种子、物理延迟及 QLA／PPO／JSEQ／Score；四方法、两负载、三延迟、五种子全部 120 项，顺序不由结果决定。每项新建队列、上传、反馈、规则与在线 H 状态，共用同一冻结外生文件、配对实测服务、位置和固定 horizon／drain；不重新生成或提前结束。当前非默认网络依旧拒绝，不能偷偷采用高带宽。
- 实测服务仅在执行 catalog 内；所有方法仅接收共同的当前元数据／过去回执／陈旧预测等待。完整实测未来记录仅导出作报告，不给 actor／QL／critic。真实 10 秒 KAIST 位置由原物理插值接口提供。
- 逐项实际评估成功后才登记原始输出、参数不变、共同请求数和未截断／drop／unfinished 数值；零完成或负面结果也保留。已完成、失败或部分 cell／整个网格的科学语义锁禁止换目录后重跑、追加或自动恢复。任何部分失败都保留已有证据，需要另行审查的新增尝试，而非合并半臂。
- 满 120 项只得到 `ALL_120_ACTUAL_CELLS_PENDING_FINAL_AUDIT.json`；不会自动审计、统计、出图或标 `complete_audited`。该实际文件目前不存在。

`check_retained_test_grid_execution.py` 仅使用明确人工描述，检查覆盖与固定顺序、自己的方法／种子路由、维度公式、缺失真实合同的早期拒绝，以及静态连接。禁止读取实际测试计时 CSV、导入 Torch、构造模型或伪造 actual-complete／权重／PASS 记录。作者自检不能证明真实加载、资源检查、协议路径保护或 120 项执行可用；这些实际路径均未执行，仍须独立复审和实际门槛。
